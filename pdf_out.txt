DEPARTMENTAL RECOMMENDATION
For Generative AI projects, the following four components are recommended
as compulsory additions to conventional software project documentation:
 Generative AI Component Analysis: explain the model, prompting
strategy, API integration, and actual role of AI.
 Prompt Engineering Evidence: document representative prompts,
input/output examples, and prompt refinements.
 AI Evaluation and Responsible AI: demonstrate output-quality testing
and address hallucinations, privacy, and relevant risks.
 Working Application Evidence: submit screenshots, test results,
repository details where applicable, and instructions to run the project.
Recommended final submission: one properly formatted PDF report, the
working application, source code or repository link, a prompt documentation
appendix, and supporting test evidence.
This is a recommended departmental template. Institute-prescribed project-report formats,
examination rules, and academic-integrity policies take precedence.
